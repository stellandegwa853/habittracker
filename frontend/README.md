# VibeCheck Frontend

This folder contains the React frontend for VibeCheck.

## What Lives Here

- `src/pages/` contains route pages such as Landing, Login, Dashboard, Habits, Calendar, Statistics, Profile, and Settings.
- `src/components/` contains reusable UI pieces such as the sidebar, topbar, habit cards, forms, timers, and empty states.
- `src/context/` contains shared app data state.
- `src/services/api.js` contains the Axios API connection to the Django backend.
- `src/utils/` contains helper functions for habit data, error messages, and timer storage.

## Commands

From the project root:

```bash
npm run dev
npm run lint
npm run build
```

Or from this folder:

```bash
npm run dev
npm run lint
npm run build
```
